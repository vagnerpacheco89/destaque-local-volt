# Destaque Local — VOLT DEV

Ambiente vivo de desenvolvimento e preview do template VOLT para eletricistas locais.

- Base inicial: checkpoint v0.22.14
- Uso: polimento visual, implementação e preview rápido
- GitHub = source of truth do código executável
- Google Drive = source of truth de produto, direção visual, copy, regras e contexto
- Produção de clientes será tratada separadamente do ambiente de desenvolvimento do template
- Dados e WhatsApp deste demo são fictícios/demonstrativos

## Fluxo atual

O trabalho normal do VOLT é feito diretamente pelo chat responsável de Produto & Desenvolvimento:

Founder dá feedback → ChatGPT analisa → implementa no repo → preview atualiza → Founder avalia → nova iteração.

Issues e PRs não são obrigatórios para alterações rápidas, reversíveis e de baixo risco.

Codex não é etapa padrão. Ele é usado somente quando uma tarefa realmente exige engenharia especializada, como refatoração ampla, bug difícil, migração, automação necessária ou auditoria técnica.

## Preview

GitHub Pages/preview é usado para avaliação rápida durante o polimento do template.

## Checkpoints

ZIPs no Google Drive ficam reservados a checkpoints importantes quando úteis; não substituem o GitHub como histórico do código.
